# Cell Biology — Sprint Week 1

## What is this?

This sprint plan is a **teacher-facing playbook** for building and reviewing Cell Biology content consistently and quickly.

It explains:
- What topics we are focusing on this week
- What "good enough to publish" looks like
- How to review lessons in under 5 minutes

This is not a lesson and is never shown to students.

This page is **not student-facing** and does **not affect published lessons**.

---

## When should I use this?

Use this page:
- Before creating or editing Cell Biology lessons
- When reviewing lessons before marking them classroom-ready
- If you are unsure what to build next or what quality bar to aim for

---

## How to use it (quick)

1. Check the **Week checklist** below  
2. Create or edit lessons as normal  
3. Before publishing, review lessons using the **5-minute review rubric**

---

## Week 1 checklist (use as guidance)

Before the end of the week, aim to:

- [ ] Review overall Cell Biology topic coverage
- [ ] Prioritise missing or weak sub-topics
- [ ] Ensure all lessons align with the exam specification
- [ ] Confirm quizzes and flashcards exist for each lesson
- [ ] Review lessons using the 5-minute review rubric

You do **not** need to complete this checklist inside the system.
It is a guide for what "good progress this week" looks like.

---

## What next?

When ready:
- Go to **Create Lesson** to build new content
- Or open an existing lesson and use **Mark as reviewed** once it passes the rubric

This sprint plan will be updated or replaced in future weeks.
