# Missing Microscopy Asset Specifications

Specifications for the four assets currently missing from the pipeline. Use this when generating or importing images to ensure consistency.

## 1. microscope-panel.png

| Field | Value |
|-------|-------|
| **Filename** | `microscope-panel.png` |
| **Purpose** | Shows microscope views and micrograph examples; helps learners understand what they see through the eyepiece. |
| **Recommended style** | Flat educational illustration, clean GCSE biology style. No labels, no watermark. |
| **Recommended background** | White. |
| **Recommended aspect ratio** | 4:3 or 3:2 (landscape). |
| **Recommended prompt** | Educational biology panel showing microscope views and micrograph examples, clean GCSE style, white background, flat illustration, no watermark. |
| **Storyboard** | Scene 3 — "Microscope Views" (split layout, right side). |
