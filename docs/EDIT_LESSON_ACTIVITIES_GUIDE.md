# Edit Lesson — Activities & Action Points Explained

This guide explains what each action on the Edit Lesson screen does and when you should use it.  
Keep this open while building a lesson so you always know what to click next and why.

---

## A. Lesson Structure & Content Activities  
These tools control what students see and learn inside the lesson.

| **Activity** | **What it does** | **When to use it (teacher guidance)** |
|--------------|------------------|----------------------------------------|
| **Pages** | Splits the lesson into separate pages that students move through in order. | Use from the start. Each page should cover one clear idea or subtopic. |
| **Add page** | Creates a new blank page. | Use when introducing a new concept, section, or phase of the lesson. |
| **Text** | Adds written teaching content (supports images and formatting). | Use for core explanations, definitions, and instructions students must read. |
| **Upload image / video** | Inserts an image or video at the cursor position. | Use when a diagram, micrograph, or animation explains better than text. |
| **Key ideas** | Highlights the most important takeaway in a styled box. | Use after teaching content to summarise what students must remember. |
| **Key words** | Displays essential terminology clearly. | Use when introducing new scientific vocabulary students must learn. |
| **Exam tips** | Shows exam-focused advice and marking guidance. | Use when content is commonly examined or has mark-scheme traps. |
| **Misconceptions** | Flags a common misunderstanding. | Use when students often confuse ideas (e.g. nucleus vs cytoplasm). |
| **Deeper knowledge** | Adds optional extension or enrichment content. | Use for higher-attaining students or beyond-spec context. |
| **Checkpoint** | Marks a pause point to check understanding. | Use after a major idea, before students move on. |
| **Diagram** | Inserts or references a diagram (optionally labelled). | Use when visual recall is essential (e.g. labelled cell diagrams). |

## B. Lesson Readiness & Teaching Actions  
These actions help you decide when a lesson is ready to teach or publish.

| **Activity** | **What it does** | **When to use it** |
|--------------|------------------|-------------------|
| **Readiness status** | Shows whether the lesson meets internal quality checks. | Use as a final self-check before publishing or teaching. |
| **Mark as reviewed** | Confirms you have checked accuracy and completeness. | Use when content, quizzes, and topic mapping are finished. |
| **Make classroom-ready** | Runs system checks and suggestions (diagrams, practice, etc.). | Use before live teaching to catch missing elements. |
| **Suggested diagrams** | Suggests diagrams based on lesson content. | Use when visuals are missing or you want quick diagram ideas. |

---

## C. Revision Materials & Practice Actions

**Important:**  
Everything here affects student revision and practice over time.  
This is separate from the Lesson Quiz ("Check your understanding").

| **Activity** | **What it does** | **When to use it (very important)** |
|--------------|------------------|-------------------------------------|
| **Generate revision with AI** | Creates draft flashcards and/or practice questions. | Use after content is stable. Always review before publishing. |
| **Flashcards** | Shows flashcards linked to this lesson or topic. | Use for definitions, processes, and quick recall. |
| **Add new flashcard** | Manually adds one flashcard (front/back). | Use when you want precise syllabus-aligned facts. |
| **Import from question bank** | Pulls existing flashcards from the topic bank. | Use to avoid duplication when content already exists. |
| **Save to bank** | Saves flashcards for reuse across lessons. | Always use if cards should be shared by topic. |
| **Quiz questions (Test yourself)** | Lesson-specific quiz shown as "Check your understanding". | Use for in-lesson understanding checks (3–5 per page ideal). |
| **Generate quiz questions (AI)** | Auto-generates quiz questions from lesson content. | Use as a starting point only; always edit. |
| **Assessments / Past papers** | Attaches exam-style practice materials. | Use later in revision or exam-prep lessons. |

---

## D. How teachers should think about using these

Use the tables above to guide your decisions as you build a lesson.

### Rule of thumb (this prevents confusion)

**Lesson Quiz ("Check your understanding")**  
→ Did the student understand *this* lesson?  
Created in **Edit Lesson → Quiz**. Shown inside the lesson.

**Practice questions / Flashcards**  
→ Can the student practise *this topic* over time?  
Created or stored in banks, reused across lessons.

**AI tools**  
→ Speed up creation. They never replace teacher review.
