# 5-Minute Lesson Review Rubric

**Non-negotiable quality gate.** If a lesson fails here, it is not Classroom-Ready.

Answer **YES** / **NO** quickly. Fix all **NO**s.

---

## 1. Topic alignment (30 seconds)
- Does the lesson clearly match the selected sub-topic?
- Would a student know exactly what they are learning?

## 2. Cognitive flow (1 minute)
- Does each page build logically on the previous one?
- Are there any "jumps" that assume prior knowledge not explained?

## 3. Visual support (1 minute)
- Do diagrams actually help understanding?
- Are diagrams placed where the explanation needs them?

## 4. Understanding checks (1 minute)
- Do checkpoints test understanding, not copying?
- Are questions phrased clearly for GCSE level?

## 5. Assessment readiness (1 minute)
- Quiz questions unambiguous?
- Flashcards concise and accurate?
- Misconceptions addressed?

---

## Final decision (30 seconds)

**Would I confidently assign this lesson to my own class?**

- **YES** → Mark reviewed
- **NO** → Fix immediately
