9 — CORE TEACHING  
Paste into: Text (concept)

<h2><strong>Teaching: Simultaneous Equations</strong></h2>  
<p>👉 The key idea is to find a pair (or more) of values that fit both equations at the same time.</p>  

<h3><strong>What happens:</strong></h3>  
<ul>  
<li>We have two equations, each relating variables like x and y.</li>  
<li>Each equation describes a condition; solving simultaneously means both must be true together.</li>  
</ul>  

<h3><strong>Method → result, step by step:</strong></h3>  
<ul>  
<li><strong>Choose a method</strong>: substitution if one variable is isolated or easily isolated; elimination if coefficients can be matched for direct elimination.</li>  
<li><strong>Substitute or eliminate</strong>: Rearrange one equation (if needed), then substitute into the other or add/subtract to eliminate one variable.</li>  
<li><strong>Solve for the first variable</strong>.</li>  
<li><strong>Substitute back</strong> to find the second variable.</li>  
<li><strong>Check</strong> the solution by plugging both values into both original equations.</li>  
</ul>  

<h3><strong>Think like an examiner:</strong></h3>  
<p>👉 Always show every line of algebra clearly labelled, give final answers with the correct value per variable, and include a quick check to prove your solution is valid.</p>

12 — COMMON MISTAKE  
Paste into: Common mistake

<p>👉 A common mistake is solving for just one variable and forgetting to substitute back to find the other.</p>  
<p>For example, you might find x = 3 but stop there without finding y.</p>  
<p>This loses marks because the solution to simultaneous equations requires values for both variables.</p>  
<p>👉 Always remember to substitute your first solution back into one of the original equations to calculate the second variable and then check both in the other equation.</p>

14 — STEP-BY-STEP PROCESS  
Paste into: Step-by-step diagram (process)

Process:  
Solving simultaneous equations by elimination

Step 1: Multiply one or both equations (if needed) so the coefficients of one variable are the same or opposites.  
↓  
Step 2: Add or subtract the equations to eliminate that variable and form an equation with one variable.  
↓  
Step 3: Solve the new equation for the remaining variable.  
↓  
Step 4: Substitute the value found back into one original equation to find the second variable.

This step-by-step method is exactly what the exam wants you to show for full method marks.

17 — WORKED EXAMPLE  
Paste into: Worked example (checkpoint)

Question:  
Solve the simultaneous equations using elimination:  
3x + 4y = 20  
5x – 4y = 8

Answer:  
<details>  
<summary>Reveal Answer</summary>

1. Add the two equations to eliminate y:  
(3x + 4y) + (5x – 4y) = 20 + 8  
3x + 5x + 4y – 4y = 28  
8x = 28  

2. Solve for x:  
x = 28 ÷ 8 = 3.5  

3. Substitute x = 3.5 into the first equation:  
3(3.5) + 4y = 20  
10.5 + 4y = 20  
4y = 20 – 10.5 = 9.5  
y = 9.5 ÷ 4 = 2.375  

4. Check by substituting x and y into second equation:  
5(3.5) – 4(2.375) = 17.5 – 9.5 = 8 ✔️

Final answer: x = 3.5, y = 2.375

</details>

22 — EXAM PRACTICE  
Paste into: Text (concept)

Question 1 (1 mark):  
Solve for x in the equation: 2x + y = 10, given y = 4.

Question 2 (2 marks):  
Use substitution to solve:  
y = x + 2  
2x + 3y = 12

Question 3 (3 marks):  
Solve by elimination:  
3x + 2y = 16  
5x – 2y = 8

Question 4 (4 marks):  
Solve the simultaneous equations:  
y = x²  
y = 5 – x

<details>  
<summary>Reveal Model Answers Q3 and Q4</summary>

Q3:  
1. Add the equations to eliminate y:  
(3x + 2y) + (5x – 2y) = 16 + 8  
8x = 24  
2. Solve for x:  
x = 24 ÷ 8 = 3  
3. Substitute x = 3 into first equation:  
3(3) + 2y =16 → 9 + 2y =16 → 2y =7 → y = 3.5  
Final answer: x=3, y=3.5

Q4:  
1. Substitute y = 5 – x into y = x²:  
x² = 5 – x → x² + x – 5 = 0  
2. Solve quadratic (using formula or factorisation):  
x = [–1 ± √(1 + 20)]/2 = [–1 ± √21]/2  
3. Calculate values approximately:  
x ≈ 1.79 or x ≈ –2.79  
4. Find y for each x:  
If x ≈1.79, y = 5 – 1.79 = 3.21  
If x ≈ –2.79, y = 5 – (–2.79) = 7.79  
Final solutions: (1.79, 3.21) and (–2.79, 7.79)

</details>

24 — KEY WORDS  
Paste into: Key words

<strong>Simultaneous equations</strong> – Two or more equations solved together for common variables.  
<strong>Substitution</strong> – Replacing one variable with an expression from another equation.  
<strong>Elimination</strong> – Adding or subtracting equations to remove one variable.  
<strong>Variable</strong> – A symbol representing an unknown value (usually x, y).  
<strong>Solution</strong> – The values of variables that satisfy all equations.  
<strong>Rearrange</strong> – Changing the equation to isolate one variable.  
<strong>Check</strong> – Substituting answers back into equations to verify correctness.  
<strong>Coefficient</strong> – The number multiplying a variable.  
<strong>Quadratic</strong> – An equation where the variable is squared (e.g., x²).  
<strong>Method</strong> – The set of steps taken to solve a problem clearly and logically.
