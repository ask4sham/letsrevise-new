9 — CORE TEACHING  
Paste into: Text (concept)

<h2><strong>Teaching: Simultaneous Equations</strong></h2>  
<p>👉 The key idea is how to find values for two unknowns using two equations.</p>  

<h3><strong>What happens:</strong></h3>  
<ul>  
<li>We have two equations, each involving two variables (like x and y).</li>  
<li>Because both equations must be true at the same time, we can use one equation to express one variable and substitute it into the other.</li>  
</ul>  

<h3><strong>Structure → function / Process → effect:</strong></h3>  
<ul>  
<li>Substitution: Express x or y from one equation → substitute into the other → reduce to 1-variable equation → solve → back-substitute to find other.</li>  
<li>Elimination: Multiply equations if needed → add or subtract equations to cancel one variable → solve single-variable equation → back-substitute.</li>  
</ul>  

<h3><strong>Think like an examiner:</strong></h3>  
<p>👉 Write each step clearly, label variables if asked, show rearrangements, and justify why you add/subtract or substitute. Marks are awarded for correct method and final answer.</p>

12 — COMMON MISTAKE  
Paste into: Common mistake

<p>👉 A common mistake is to forget to multiply one or both equations by the right number when using elimination, which leads to variables not cancelling properly.</p>  
<p>👉 Always check coefficients carefully before adding or subtracting equations, so terms cancel exactly.</p>  
<p>👉 Doing this correctly earns method marks—even if the final answer needs correcting.</p>

20 — SELF-CHECK QUESTION  
Paste into: Self-check question

Question:  
Solve these simultaneous equations by substitution:  
x + y = 7  
x - y = 3  

Answer:  
<details>  
<summary>Reveal Answer</summary>  

From x + y = 7 → y = 7 - x  
Substitute into x - y = 3:  
x - (7 - x) = 3  
x - 7 + x = 3  
2x - 7 = 3  
2x = 10  
x = 5  
Back-substitute y = 7 - 5 = 2  
Solution: x = 5, y = 2  

</details>  

21 — EXAM PRACTICE  
Paste into: Text (concept)

<p><strong>Q1 (1 mark):</strong> What does it mean to solve simultaneous equations?</p>  

<p><strong>Q2 (2 marks):</strong> Solve these equations by elimination: 2x + 3y = 10 and 4x - 3y = 8.</p>  

<p><strong>Q3 (3 marks):</strong> Use substitution to solve: y = 2x + 1 and 3x + y = 7. Show all steps clearly.</p>  

<p><strong>Q4 (4 marks):</strong> A store sells pens and notebooks. Two pens and three notebooks cost £12. Three pens and two notebooks cost £13. Form simultaneous equations and solve them to find the price of one pen and one notebook.</p>  

<details>  
<summary>Reveal Model Answers</summary>  

Q1:  
Solving simultaneous equations means finding values of variables that satisfy both equations at the same time.  

Q2:  
2x + 3y = 10  
4x - 3y = 8  
Add equations: (2x+4x) + (3y - 3y) = 10 + 8 → 6x = 18  
x = 3  
Substitute x into first: 2(3) + 3y = 10 → 6 + 3y = 10 → 3y = 4 → y = 4/3  

Q3:  
y = 2x + 1  
3x + y = 7  
Substitute y: 3x + (2x + 1) = 7 → 5x + 1 = 7 → 5x = 6 → x = 6/5  
Find y: y = 2(6/5) + 1 = 12/5 + 1 = 17/5  

Q4:  
Let p = price of pen, n = price of notebook  
2p + 3n = 12  
3p + 2n = 13  
Multiply first by 2: 4p + 6n = 24  
Multiply second by 3: 9p + 6n = 39  
Subtract first from second: (9p-4p) + (6n-6n) = 39 - 24 → 5p = 15 → p = 3  
Substitute p=3 into 2p + 3n =12 → 2(3) + 3n = 12 → 6 + 3n = 12 → 3n = 6 → n = 2  

</details>

23 — KEY WORDS  
Paste into: Key words

<strong>Simultaneous equations</strong> – Two or more equations solved together to find common variable values.  
<strong>Substitution</strong> – Replacing a variable with an equivalent expression from another equation.  
<strong>Elimination</strong> – Adding or subtracting equations to remove one variable.  
<strong>Variable</strong> – A letter representing an unknown value.  
<strong>Coefficient</strong> – The number multiplying a variable.  
<strong>Back-substitution</strong> – Using a found value to solve for another variable.  
<strong>Solution</strong> – The values of variables that satisfy all equations.  
<strong>Linear equation</strong> – An equation where variables appear to the first power only.  
<strong>Consistent system</strong> – A system with at least one solution.  
<strong>Method marks</strong> – Exam marks awarded for correct working steps, even if the final answer is wrong.
